# Pal Android Native UI Starter

This is an initial native Android UI prototype for Pal, built with Kotlin and Jetpack Compose.

- App and backend are separate repositories.
- This version is UI-only; buttons and feed actions are placeholders.
- GitHub Actions builds the debug APK when pushed to `main` or run manually.
- No backend changes or Firebase integration are included yet.

Package: `com.pal.app`


## Android resources added
- PAL palette colors and strings
- Dark platform theme
- Vector P logo and navigation/action icon drawables
- Adaptive launcher icon using the blue PAL P
